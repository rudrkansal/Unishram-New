# UniShram

India's unified labour marketplace — daily-wage workers, contractors, clients
and material vendors, in one app. Bilingual-first (23 scheduled languages),
built for low-literacy users, with Aadhaar-verified trust badges, wage
protection against the legal minimum, and voice control for hands-free use.

See [BUILD_PROGRESS.md](BUILD_PROGRESS.md) for what's built and what's left,
[SETUP.md](SETUP.md) for machine setup and store submission, and
[VOICE.md](VOICE.md) for how the voice features work.

## Getting started

```bash
export PATH="$HOME/development/flutter/bin:$PATH"
flutter pub get
flutter run
```
